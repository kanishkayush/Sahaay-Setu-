# Changelog — sahaay-frontend

## 1.0.0 — 2026-09-07

Initial skill, extracted from the conventions established while building the v0 app.

- 12 rules across 6 prefixes: `flow-`, `i18n-`, `ui-`, `a11y-`, `money-`, `honesty-`
- Core principles cover the data-flow boundary, hardcoded strings, the shared `Text`
  component, the accessibility floor, graceful degradation, and honesty about unverified data
